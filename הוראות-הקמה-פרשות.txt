מה כבר מוכן:
  * ריפו בגיטהאב:  shiurim-parasha
  * דלי בענן:      shiurim-parasha
  * כתובת ציבורית: מוגדרת וכבר בתוך index.html
  * האתר באוויר ומציג "בהקמה"

מה נשאר: להקים תיקייה במחשב שתזין אותו.


-----------------------------------------------------------
צעד 1 - יצירת התיקייה
-----------------------------------------------------------

ליצור על שולחן העבודה תיקייה חדשה בשם:

   שיעורי פרשת שבוע

(השם לא משנה לקוד - הסקריפטים מאתרים את עצמם.)

לתוכה להעתיק את ארבעת הקבצים שקיבלת:
   upload.ps1
   make_list.ps1
   העלה שיעורי פרשה.bat
   .gitignore
   index.html      (זה שקיבלת, אחרי שינוי השם)

בנוסף - להעתיק לשם את rclone.exe מתיקיית המשניות
(אותו קובץ בדיוק, פשוט עותק).

הערה: הקובץ .gitignore מתחיל בנקודה. אם Windows לא נותן
לשמור שם כזה, ליצור אותו דרך הסקריפט בצעד 3 (ראו למטה).


-----------------------------------------------------------
צעד 2 - יצירת תיקיות החומשים
-----------------------------------------------------------

בתוך התיקייה ליצור חמש תיקיות:

   בראשית
   שמות
   ויקרא
   במדבר
   דברים

לתוכן ייכנסו קבצי השמע, לפי החומש של הפרשה.

תזכורת לשם הקובץ:

   פרשת_בראשית_תשפו.mp3

שם הפרשה, קו תחתון, השנה בלי גרשיים. אם השיעור מתפצל:
פרשת_נח_תשפו_חלק_א.mp3 ו-פרשת_נח_תשפו_חלק_ב.mp3


-----------------------------------------------------------
צעד 3 - חיבור התיקייה לגיטהאב
-----------------------------------------------------------

לפתוח PowerShell בתוך התיקייה החדשה. הדרך הקלה: לפתוח
את התיקייה בסייר, ללחוץ על שורת הכתובת למעלה, להקליד
powershell ולאשר.

ואז להריץ את הפקודות אחת-אחת, לפי הסדר:

git init

git branch -M main

git remote add origin https://github.com/danvlado1234-sketch/shiurim-parasha.git

git fetch origin

git reset origin/main

מה זה עשה: הפך את התיקייה לריפו, חיבר אותה לריפו בגיטהאב,
ומשך משם את index.html הקיים בלי לדרוס כלום מקומית.

אם .gitignore לא נוצר בצעד 1, אפשר ליצור אותו כאן:

"*.m4a`n*.mp3`nrclone.exe`nThumbs.db`ndesktop.ini" | Out-File -Encoding utf8 .gitignore


-----------------------------------------------------------
צעד 4 - בדיקות לפני ההרצה הראשונה
-----------------------------------------------------------

בדיקה 1 - החיבור לענן מכיר את הדלי החדש:

.\rclone.exe lsd r2:

   מצפים: רשימה שכוללת גם shiurim וגם shiurim-parasha.
   אם shiurim-parasha לא מופיע - המפתח הקיים מוגבל לדלי
   הישן, ויש ליצור ב-Cloudflare מפתח עם הרשאה לכל
   החשבון (אז נעדכן את rclone.conf).

בדיקה 2 - git מחובר נכון:

git status

   מצפים: On branch main, ורואים את index.html.


-----------------------------------------------------------
צעד 5 - השיעור הראשון
-----------------------------------------------------------

1. להכניס קובץ שמע אחד לתיקיית החומש המתאים, בשם תקין.
2. דאבל-קליק על "העלה שיעורי פרשה.bat".
3. לצפות לשלושה שלבים ירוקים: העלאה לענן, יצירת list.json,
   דחיפה לגיטהאב.
4. לחכות דקה ולפתוח בגלישה בסתר:

   https://danvlado1234-sketch.github.io/shiurim-parasha/

   הודעת "בהקמה" תיעלם מעצמה, החומש יידלק, ובתוכו הפרשה
   עם נגן.

אם הנגן לא משמיע: כמעט תמיד זה שם הקובץ. להשוות בדיוק
לתבנית שבצעד 2.


-----------------------------------------------------------
כללי ברזל (זהים לאתר המשניות)
-----------------------------------------------------------

* אחרי עריכה דרך האתר של GitHub - להריץ במחשב:
  git pull origin main --no-rebase --no-edit

* index.html מעלים רק בכפתור Upload files, לא בהדבקה.

* בדיקת האתר תמיד בגלישה בסתר.

* אסור: --force, reset --hard, clean -fd, rclone sync.
