צעד 1 - יצירת התיקייה
-----------------------------------------------------------

ליצור על שולחן העבודה תיקייה חדשה בשם:

   שיעורי פרשת שבוע

(השם לא משנה לקוד - הסקריפטים מאתרים את עצמם.)

לתוכה להעתיק את rclone.exe מתיקיית המשניות (אותו קובץ
בדיוק, פשוט עותק). שאר הקבצים (upload.ps1, קובצי ה-bat,
index.html, .gitignore) יגיעו מגיטהאב בצעד 3.


-----------------------------------------------------------
צעד 2 - תיקיות החומשים והמועדים
-----------------------------------------------------------

בתוך התיקייה ליצור שש תיקיות:

   בראשית
   שמות
   ויקרא
   במדבר
   דברים
   מועדים

בתוך "מועדים" - תת-תיקייה לכל מועד, למשל:
   מועדים\חנוכה
   מועדים\ראש השנה

שמות הקבצים:

   פרשה:   פרשת_בראשית_תשפו.m4a        (בתיקיית החומש)
   מועד:   חנוכה_תשפו.m4a              (בתיקיית המועד)

שם הפרשה/המועד, קו תחתון, השנה בלי גרשיים. אפשר m4a או mp3.
תוספות אופציונליות בסוף השם (לפי הסדר הזה):

   _שיעור_ב     שיעור נוסף ונפרד על אותה פרשה באותה שנה
   _חלק_ב       המשך של אותו שיעור (הקלטה שנחתכה)
   _שבת_הגדול   שבת מיוחדת (שובה/זכור/פרה/החודש/חזון/נחמו...)
   _עיון        שיעור עיוני/הלכתי (תמיד אחרון). אחריו אפשר לכתוב את
                נושא השיעור, והוא יהיה הכותרת שלו באתר (ואפשר לחפש לפיו).
                בנושא מותר גרש: _עיון_לקיחת_ד'_מינים
                מרכאות אי אפשר בשם קובץ - כותבים שני גרשים '' והאתר
                מציג מרכאות: _עיון_הלכות_חוה''מ  ->  הלכות חוה"מ

לדוגמה:  פסח_תשפו_שבת_הגדול.m4a
         שבעה_עשר_בתמוז_תשפו_עיון.m4a
         סוכות_תשפז_עיון_לקיחת_ד'_מינים.m4a

סיכום PDF: שם זהה לקובץ השמע, רק עם סיומת pdf, באותה
תיקייה. באתר יופיע אוטומטית כפתור "סיכום" ליד השיעור.

הסקריפט מתקן לבד שלושה דברים נפוצים: הקלטות וואטסאפ שנשמרו
כ-mp4 (הופכות ל-m4a), רווחים בשם הקובץ (הופכים לקו תחתון), וגרשיים
בשנה (תשפ"ז הופך לתשפז).

ובנוסף בודק כל שם לפני ההעלאה, ומזהיר בחלון ובדף הסטטוס על קובץ
שלא יופיע באתר: שם פרשה שגוי (עם הצעה, למשל "האם התכוונת לפינחס?"),
שנה חסרה, סיכום PDF בלי קובץ שמע באותו שם, או שני שיעורים זהים
שצריך להבדיל ביניהם ב-_שיעור_א / _שיעור_ב.


-----------------------------------------------------------
צעד 3 - חיבור התיקייה לגיטהאב
-----------------------------------------------------------

לפתוח PowerShell בתוך התיקייה החדשה. הדרך הקלה: לפתוח
את התיקייה בסייר, ללחוץ על שורת הכתובת למעלה, להקליד
powershell ולאשר.

ואז להריץ את הפקודות אחת-אחת, לפי הסדר:

git init

git branch -M main

git remote add origin https://github.com/danvlado1234-sketch/shiurim-parasha.git

git fetch origin

git reset origin/main

git checkout -- .

מה זה עשה: הפך את התיקייה לריפו, חיבר אותה לריפו בגיטהאב,
ומשך משם את כל הקבצים (index.html, upload.ps1, קובצי ה-bat,
.gitignore). קובצי שמע ו-PDF לא נוגעים בהם - הם חסומים
ב-.gitignore ולעולם לא עולים לגיטהאב.


-----------------------------------------------------------
צעד 4 - בדיקות לפני ההרצה הראשונה
-----------------------------------------------------------

בדיקה 1 - החיבור לענן מכיר את הדלי:

.\rclone.exe lsd r2:

   מצפים: רשימה שכוללת גם shiurim וגם shiurim-parasha.
   אם shiurim-parasha לא מופיע - המפתח הקיים מוגבל לדלי
   הישן, ויש ליצור ב-Cloudflare מפתח עם הרשאה לכל
   החשבון (אז נעדכן את rclone.conf).

בדיקה 2 - git מחובר נכון:

git status

   מצפים: On branch main, בלי קבצים ששונו.


-----------------------------------------------------------
צעד 5 - מייל לרשימת תפוצה (אופציונלי)
-----------------------------------------------------------

בכל העלאה של שיעור חדש נשלח מייל (Bcc) לרשימת התפוצה, עם
קישור לשיעור ועם השמע מצורף אם הוא קטן מ-18MB. אם חסר אחד
משני הקבצים הבאים - שלב המייל פשוט מדלג, בלי להפריע לשאר.

1. mailing-list.txt - בתיקייה הראשית, כתובת מייל בכל שורה.
   שורה שמתחילה ב-# נחשבת הערה. (חסום ב-.gitignore - לא
   עולה לגיטהאב.)

2. קובץ הגדרות בנתיב:
      %APPDATA%\shiurim-mail\mail-config.json
   בתוכן:
      { "FromEmail": "הכתובת@gmail.com", "AppPassword": "סיסמת-אפליקציה" }
   AppPassword = סיסמת אפליקציה של Gmail (לא הסיסמה הרגילה),
   נוצרת בהגדרות האבטחה של חשבון גוגל.


-----------------------------------------------------------
צעד 6 - השיעור הראשון
-----------------------------------------------------------

1. להכניס קובץ שמע אחד לתיקייה המתאימה, בשם תקין.
2. דאבל-קליק על "העלה שיעורי פרשה.bat"
   (או "העלה בלי מייל.bat" - להשלמת שיעורים משנים קודמות:
   אותו דבר, בלי שליחת מייל ובלי שהשיעור יופיע באתר
   ב"חדש השבוע").
3. נפתח בדפדפן דף סטטוס שמראה כל שלב: העלאה לענן, עדכון
   הרשימה, פרסום באתר, מייל.
4. לחכות דקה ולפתוח בגלישה בסתר:

   https://danvlado1234-sketch.github.io/shiurim-parasha/

   הפרשה תופיע עם נגן.

אם השיעור לא מופיע או הנגן לא משמיע: כמעט תמיד זה שם
הקובץ. להשוות בדיוק לתבנית שבצעד 2.
